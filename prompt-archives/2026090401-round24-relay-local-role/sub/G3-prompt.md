## Background
In hub mode renaming a node is a hub API call that patches `nodes.name` and broadcasts. In relay mode there is no hub, so renaming another node is impossible today (doc §9 says so). Add a signed key-log record type `rename-node` so any node holding the root key (or a passkey) can rename any node; every node applies it locally.
