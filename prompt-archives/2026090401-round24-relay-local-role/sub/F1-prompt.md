## Background
Settings → 节点 tab (`apps/fe/src/pages/settings/nodes/`). Today the "uplink" (which upstream this machine attaches to: a Hub, or a public 中继/relay) is shown inside node management (`management/nodes-management.tsx` → `relay/uplink-section.tsx`), where a `Network` icon dropdown switches between hub and relay mode and holds all relay actions. The product decision: **that whole thing moves into the 本机 card (`local-machine-card.tsx`) as two tabs — 「接入 Hub」 and 「接入中继」**. Selecting the Hub tab shows the hub-related UI; selecting the 中继 tab shows the relay-related UI. Node management keeps only the node table + enrollment (add node) + node actions. No more Network icon menu in node management.
