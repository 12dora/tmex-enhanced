1. **[major] `packages/stores/src/site.ts:210` — remote runtimes can still alter the global theme preset.** `selectThemePreset` unconditionally writes to the shared UI store before calling the guarded `updateTheme`. On `/n/<id>/...`, choosing a preset therefore changes the browser-wide CSS preset and may combine a light preset with the existing dark appearance. Guard the entire browser-pref mutation with `controlsBrowserPrefs`; if the theme menu must remain functional on remote routes, bind it to the self runtime instead.

Re-enabling a hidden device can consequently place it unpredictably and corrupt the intended full order. Merge `nextIds` back into the visible slots of the complete sorted device list, preserving hidden IDs in their existing slots, and submit that full sequence.

Resolve the selected device from the node-specific route and include it when filtering the offline inventory.
