## What is fine

- Paths, methods, success fields, standalone/mesh gating, setup `404 not_standalone`, and mesh `401 {error:{code:"UNAUTHORIZED",message}}` conform to the contract.
- Precheck is restricted to `/healthz`, HTTPS except permitted non-production localhost HTTP, rejects redirects, and uses a five-second abort signal.
- Passwords and join tokens are not logged or echoed in errors.
- Env replacement uses a temporary file plus atomic rename and preserves unrelated key/value entries. In valid production startup, `TMEX_FE_DIST_DIR` is mandatory and validated before assembly, so `resolveInstallDir()` does not reach its cwd fallback.
- `createAuthContextFromDb` shares the gateway DB, opens no second connection, and its no-op close cannot close the gateway DB. Gateway migrations run before it is created; migration `0020` is now registered.
- `PROCESS_STARTED_AT` is shared by gateway and assembled mesh health responses.
- `performHubJoin` preserves CLI URL/insecure-local behavior, env/restart handling, logs, and return shape. The listed `JoinError` mappings are covered.
- User/root/self-admission writes are transactionally committed inside `bootstrapUserWithSelfAdmit`; the explicitly allowed hub env-write failure leaves the user, schedules no restart, and reports that partial state.
- The 300 ms delay and shutdown ordering give the small JSON response time to flush; graceful shutdown is bounded by the existing 20-second timeout, aside from the exit-code deviation above.
