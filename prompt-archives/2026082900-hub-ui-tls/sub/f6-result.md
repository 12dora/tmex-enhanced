**zh decision — "Hub" over "中枢":** the CLI (`tmex-cli hub join`), the role value (`hub,node`) and
the env keys all say `hub`. Translating it to 中枢 in the UI would break the link between what the
user reads and what the user types, so the loanword is kept and always capitalised as a proper noun.

**Jargon removed everywhere** (verified by scan): `join 串` / join string, key log / 密钥日志 /
キーログ, `sk_sess`, root key / 根钥, epoch, enrollment, mesh, redeem, SPKI, "entry" / 入口 /
エントリ, "revoke" as a user-facing verb, certificate-internals explanations. The only remaining
technical strings are ones the user must act on: `X-Forwarded-Proto/For`, `Zone:DNS:Edit`,
`HTTP-01`/`DNS-01`, ICE diagnostics labels (a troubleshooting popover), and `hub.lan` in a
placeholder.

## Content corrections made along the way

- `nodes.setup.precheck.httpsHint` was factually **stale**: it claimed tmex cannot terminate HTTPS
  and that built-in HTTPS "comes in a later release". The HTTPS section now exists, so the string
  points at it instead.
- `nodes.setup.result.fingerprint` said "Root key fingerprint"; it now says "Account fingerprint"
  (the value shown is the account's identity fingerprint).
- `nodes.columns.reach` ("Reach") → "Connection" / 连接方式 / 接続経路, with values
  Local network / Via hub / Unreachable.
- `nodes.status.revoked` + `nodes.actions.revoke` moved from "Revoked/Revoke" to
  "Removed/Remove" (移除 / 削除). Only copy changed — code identifiers, `data-testid`s and the
  `revoke` API remain untouched.

## Open issues / out-of-scope requests

1. **`nodes.setup.precheck.docsHint` still prints a repo path** (`docs/hub/2026082800-hub-node-operations.md`)
   in the product UI. That path means nothing to someone running an installed build. Removing the
   `<p>{t('nodes.setup.precheck.docsHint')}</p>` line in
   `apps/fe/src/pages/settings/nodes/setup/become-hub-form.tsx:297` (or replacing it with a real
   docs link) is a **code** change and therefore outside my file scope — the string itself has been
   shortened for now.
2. **`nodes.enrollment.joinCommand` renders a shell command** built from `tmex-cli`. That is fine
   for the target audience, but the surrounding copy no longer explains the internals; if the
   product later gains a non-CLI join flow, this block should be revisited.
3. `nodes.https.badge`/ICE diagnostics labels (`nodes.badge.iceState`, `localCandidate`, …) keep a
   small amount of WebRTC vocabulary on purpose — that popover exists only for troubleshooting a
   failing direct connection, and renaming ICE would make it useless when comparing with browser
   diagnostics.
