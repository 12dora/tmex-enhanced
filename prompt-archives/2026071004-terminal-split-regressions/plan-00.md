# 终端分屏视觉与交互退化排查计划

日期：2026-07-10

## 目标

定位 split handle、pane 标题栏背景和 pane 拖拽预览色块同时缺失的根因，给出可复现证据与最小修复范围。

## 排查步骤

1. 在当前 task 开发服务与独立 E2E 环境中复现三项现象，记录 DOM、computed style、pointer 命中区域与截图。
2. 追踪 `@tmex/terminal-ui` 的 `SplitTerminalArea`、其布局几何和相关样式的渲染数据流，确认三个元素是否未渲染、透明、被遮挡或事件层拦截。
3. 对比近期提交及已知正常实现，列出影响 JSX、CSS token、z-index、pointer-events 或颜色变量的差异。
4. 形成单一可验证的根因假设。若用户要求修复，再先写会失败的回归测试，按 TDD 做最小修改并重新验证。

## 验收标准

- 能说明每个症状的直接技术原因，以及三者是否具有共同根因。
- 证据可由代码位置、浏览器检查或历史 diff 复核。
- 不在未确认根因前修改生产代码。
