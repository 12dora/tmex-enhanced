# tmex 多主题代码勘察报告

结论先行：

- 当前主题状态不是纯前端状态：`SiteStore` 会通过 `/api/settings/theme`、WebSocket 和数据库同步主题；`UIStore` 的 `tmex-ui` localStorage 只承担本地即时生效和离线回退。
- 当前主题只有 `light | dark`。`data-theme-preset` 是另一套独立机制，仅覆盖 CSS 变量，没有对应的用户选择 UI，也不会自动切换 `.dark`。
- Tailwind 的 `dark:` 变体依赖 `.dark` 类，因此 Dracula、Tokyo Night 等深色主题必须同时应用 `.dark`。
- 终端主题目前是 `packages/shared/src/appearance.ts` 中的两个硬编码对象，没有从 CSS 变量读取；Ghostty 已支持运行时 `setTheme()`。

### Light/dark 表达方式

`tokens.css:1-3` 明确写着：

```css
:root { /* Light theme */ }
.dark { /* Dark theme */ }
```

当前没有 `prefers-color-scheme`，也没有 `data-theme="light|dark"`。主题通过：

```tsx
document.documentElement.classList.toggle('dark', isDark)
```

实现。

默认 light token 位于 `tokens.css:2-68`，dark 覆盖位于 `tokens.css:70-105`。

### `tokens.generated.css` 的来源

`tokens.generated.css:1` 标记为自动生成：

```css
/* Auto-generated by scripts/theme/build-shortcut-tokens.ts. Do not edit manually. */
```

生成脚本是：

- `scripts/theme/build-shortcut-tokens.ts:1-25`
- 输入：`packages/theme/src/terminal-shortcut-tokens.ts`
- 输出：`packages/theme/src/tokens.generated.css`
- 写文件：`scripts/theme/build-shortcut-tokens.ts:24`

`packages/theme/package.json` 没有生成脚本；根目录 `package.json` 也没有注册该脚本。通常需要直接运行：

```bash
bun scripts/theme/build-shortcut-tokens.ts
```

### 是否支持 live re-theme

支持。

`useTerminalBootSurface.ts:319-320` 在主题变化后执行：

```ts

```

Ghostty：

- 初始主题：`packages/ghostty-terminal/src/terminal.ts:179`
- live 更新：`terminal.ts:552-557`
- Canvas renderer 更新：`canvas-renderer.ts:241-244`

因此新主题可以复用现有 live `setTheme()` 链路。

`TerminalPreview.tsx:165-171` 则把主题作为创建依赖，主题变化时更偏向于重建预览终端，而不是只调用 live update。

### 推荐接入位置

建议：

1. 在 shared theme registry 中为每个主题定义完整 `TerminalThemeColors`；
2. `packages/theme` 负责主题定义和 UI token；
3. `packages/terminal-ui` 接受 `ThemeId` 或完整 `TerminalThemeColors`；
4. `device-console.tsx` 通过 `resolveTheme(themeId)` 取得终端对象；
5. `useTerminalBootSurface` 继续使用 `instance.setTheme()`；
6. tmux/OSC 继续从同一份主题对象派生 foreground/background。

注意：Gateway 当前只使用终端的 foreground/background：

- `appearance.ts:82-92`
- `getTmuxWindowStyle()`
- `getOsc11ResponseColor()`

ANSI 16 色目前只作用于前端终端。

### 重要设计限制

当前服务端保存的是站点级 `SiteSettings.theme`，不是单用户偏好。

如果要支持命名主题并继续跨页面、跨客户端广播，需要扩展：

- `ThemeMode` 为 `ThemeId`
- 数据库 CHECK 约束和迁移
- Gateway API 校验
- WS 类型、Borsh 编码、decoder、builder
- tmux broadcaster
- 相关测试

`system` 有一个特殊问题：它依赖每个客户端的操作系统。如果服务端广播 `system`，不同客户端可能解析出不同的具体主题。建议明确选择：

1. `system` 只作为本地 UI 偏好，服务端只同步具体主题；
2. 服务端也保存 `system`，每个客户端本地解析为默认 light/dark。

## 建议的数据模型

建议把主题定义拆成“选择值”和“具体主题定义”：

```ts
export type ThemeId =
  | 'system'
  | 'default-light'
  | 'default-dark'
  | 'dracula'
  | 'tokyo-night'
  | 'tokyo-night-storm'
  | 'tokyo-night-light'
  | 'catppuccin-mocha'
  | 'catppuccin-latte'
  | 'nord'
  | 'one-dark'
  | 'solarized-dark'
  | 'solarized-light'
  | 'gruvbox'
  | 'github-light'
  | 'github-dark'

export type ThemeAppearance = 'light' | 'dark'

export interface ThemeUiTokens {
  background: string
  foreground: string
  card: string
  cardForeground: string
  popover: string
  popoverForeground: string
  primary: string
  primaryForeground: string
  secondary: string
  secondaryForeground: string
  muted: string
  mutedForeground: string
  accent: string
  accentForeground: string
  destructive: string
  border: string
  input: string
  ring: string
  chart: [string, string, string, string, string]
  radius: string
  sidebar: string
  sidebarForeground: string
  sidebarPrimary: string
  sidebarPrimaryForeground: string
  sidebarAccent: string
  sidebarAccentForeground: string
  sidebarBorder: string
  sidebarRing: string
  chatSurface: string
  code: Record<string, string>
  fullCalendar: Record<string, string>
}

export interface ThemeDefinition {
  id: Exclude<ThemeId, 'system'>
  labelKey: string
  appearance: ThemeAppearance
  ui: ThemeUiTokens
  terminal: TerminalThemeColors
}

export function resolveTheme(
  id: ThemeId,
  prefersDark: boolean,
): ThemeDefinition
```

`system` 通过 `resolveTheme()` 映射为：

- OS dark：`default-dark`
- OS light：`default-light`

旧值迁移：

```text
light -> default-light
dark  -> default-dark
```

建议由主题应用函数统一完成：

```text
data-theme="<selected id>"
data-theme-appearance="<resolved appearance>"
.dark              // resolved appearance === "dark"
CSS variables      // resolved.ui
terminal object    // resolved.terminal
```
