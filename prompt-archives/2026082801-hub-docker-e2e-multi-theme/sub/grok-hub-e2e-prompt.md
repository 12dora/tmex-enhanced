## Topology (docker compose, project name `tmex-e2e`)
- networks: `edge` (caddy, hub, node-a), `uplink-a` (hub, node-a), `uplink-b` (hub, node-b), `lan` (node-a, node-b; connectable/disconnectable at runtime with `docker network disconnect` to force relay vs LAN).
