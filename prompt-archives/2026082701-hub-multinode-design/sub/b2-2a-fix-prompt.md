# Task B2-2a-fix — address security/lifecycle review of the mesh transport plane

Context: `apps/gateway/src/mesh/**` transport files (report `sub/b2-2a-result.md`; design §2 "链路身份与握手", §3). Review: `sub/b2-2a-review.md` — the coordinator judged ALL items valid, with these decisions:

1. **Uplink signing oracle (blocker)**: add `packages/shared/src/auth/uplink-auth.ts` exporting `DOMAIN_UPLINK_AUTH = 'tmex/uplink-auth/v1'`, Borsh `UplinkAuthSchema {domain, nonce[32], hub_host: string}` and `uplinkAuthMessage(nonce, hubHost)`; export from the auth barrel. `UplinkClient` accepts `auth.challenge` only once, only in `authenticating` state, requires exactly 32 bytes, and signs `uplinkAuthMessage(nonce, <host of hubUrl>)`. (The hub verifier is patched by a separate follow-up — write the shared helper + a test vector so both sides agree; also update `apps/gateway/src/mesh/*.test.ts` fakes.)
2. **Plaintext ws-direct (blocker)**: until Phase 3 replaces the data plane with a DataChannel, the ws-direct path MUST run `SecureChannelLink` over the WS exactly like relay (same handshake with `eph_x25519_pk`, transcript `path:'relay'` — document that `'dc'` is reserved for the real DataChannel binding with fingerprints). No plaintext business bytes on any peer path. Rename the transport kind to `'ws-secure'`.
3. **Header filtering (blocker)**: `openHttpStream` strips `cookie / authorization / host / connection / upgrade / proxy-* / x-forwarded-* / x-tmex-via` from the outgoing OPEN headers (defense in depth; the forwarder in B2-2b applies the response policy) and never forwards `set-cookie` from the target — `acceptHttpStream` also strips `set-cookie` from the target's response before encoding the head. Add tests.
4. **Trusted via (blocker)**: `dispatchHttp(request, ctx: { uid: string | null; viaNodeId: string; renewedExpiresAt?: number })` — `GatewayRuntime.dispatchHttp` stores the ctx in an exported `WeakMap<Request, DispatchContext>` (`apps/gateway/src/mesh/types.ts` → `requestDispatchContext`) and also puts `via`/`uid` on `ApiRouteContext` (`apps/gateway/src/api/route.ts` add optional `mesh?: DispatchContext`). `acceptHttpStream` passes `viaNodeId = peer node id` from the authenticated link, never from OPEN/body. Only touch the `dispatchHttp` lines in `runtime.ts` (another agent is editing its Bun close callbacks concurrently — use minimal, targeted edits).
5. Body streaming: `Request.body` is a pull-based stream reading one LinkStream chunk per pull; no background greedy loop, no unbounded array.
6. RST/cancel: one AbortController per stream on each side; peer RST cancels the entry's request-body reader and the target's response-body reader; target ends the response (`await stream.end()`) before/instead of `reset()` on the request direction so a complete early response is never clobbered — define the state precisely and test the "infinite upload + immediate 413" case.
7. WS stream sessions: keep `{sid, via, uid}` on the stream session; before dispatching each complete Borsh frame call `NodeSessionStore.verify` (throttled renewal applied; failure → RST + close); on graceful END from either side run an idempotent teardown that ends the other direction too so `stream.closed` resolves and PeerManager counts drop; `onClose` never double-fires.
8. `verifyAuth` keeps `renewedExpiresAt` and `acceptHttpStream` injects `x-tmex-session-renewed` on success responses.
9. `UplinkClient`: connect timeout (10 s) and auth timeout (10 s) → close + backoff; every non-stop link closure tears down link + heartbeat, sets offline, then backs off (1–60 s, jitter), `attempt` reset only after a successful auth **and** ≥ 30 s uptime; catch-up: per-user serial queue targeting `{seq, hash}`, apply strictly by seq, compare head hash at target (mismatch → surface `key_log_fork` event and stop), no concurrent `key.log.req`.
10. `PeerManager`: deterministic arbitration on simultaneous dial (keep the connection initiated by the lexicographically smaller nodeId; close the other), generation counter + AbortController so `stop()` cancels pending dials and stale callbacks never re-arm idle timers; unknown/unallowed OPEN types → `stream.reset('unknown-stream-type')` and not counted; per-link concurrent stream cap 256.
11. `LinkStreamCarrier.close()` = closing state (reject new sends, drain accepted queue, then `await stream.end()`); `terminate()` = RST immediately.
12. `PeerServer`: try each bind host, aggregate errors, throw only if none bound; rate limiter counts only valid WebSocket upgrade attempts and evicts idle IPs (bounded TTL map).
13. `ctl.ts sleep()`: remove the abort listener on both paths.
