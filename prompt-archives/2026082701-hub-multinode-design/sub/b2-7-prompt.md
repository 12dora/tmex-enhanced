4. **Trust gates**: `getLink()`, `receiveRtcSignal()`, endpoint/reach enumeration, `peer_cache` writes all require a present, same-user, non-revoked `node_certs` row; un-admitted nodes from `node.list` are ignored entirely (no cache row, no dial); test asserts zero dial attempts with an observable fake endpoint.

6. **Shutdown**: single `shutdownPromise` shared by restart callback and signals with the 20 s budget; each stage's failure logged and the next stage still runs (peer → uplink → hub → gateway); test.
7. **Integration tests made non-vacuous** (`mesh.integration.test.ts`): (a) attacker completes a real peer/relay handshake with A's certificate, then sends forged-sid HTTP/WS and a structurally valid delegation signed with A's node key → assert specific auth error codes (no 503 pass-through); (b) forged `node.list` injected via the real uplink with a reachable fake endpoint → assert no peer_cache row, zero dials, error = not admitted; (c) relay ciphertext test asserts captured bytes non-empty and free of Borsh magic / HTTP OPEN plaintext across fragment boundaries, and decrypts the captured stream with the test-side keys to prove it is this request; (d) upload-cancel test waits on a latch from B's dispatch before aborting.
