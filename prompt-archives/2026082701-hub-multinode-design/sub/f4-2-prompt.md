## Context

tmex is becoming a mesh of nodes; the browser talks to an "entry" node and reaches other nodes through paths prefixed `/n/:nodeId` (`/n/:id/api/...`, `/n/:id/ws`), where `nodeId = self` means the entry itself (and the un-prefixed legacy routes stay equivalent to `self`). Design: `docs/hub/2026082700-hub-node-architecture.md` §4 "每 node 一套运行时". The Phase-0 exploration `prompt-archives/2026082701-hub-multinode-design/sub/e0-2-result.md` lists every URL-construction point that bypasses `ApiClient` and every place where a single global runtime is assumed — that file is your work list; read it fully first, then `prompt-archives/2026082701-hub-multinode-design/phase0-result.md` section "E0-2" for the decisions.

Routing (`apps/fe/src/main.tsx` and routing files): `/n/:nodeId/devices/:deviceId[/windows/:windowId/panes/:paneId]`, `/n/:nodeId/file/:ref`, `/n/:nodeId/settings`; legacy `/devices/...`, `/file/...`, `/settings` are the `self` equivalents (no redirect needed, they render inside the `self` boundary).
