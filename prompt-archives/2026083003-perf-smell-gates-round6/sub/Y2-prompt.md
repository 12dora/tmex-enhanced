## Task Y2 — Gateway performance round 2: tmux control plane, persistence write frequency, agent streaming, files/watch
Round 1 already landed (read `prompt-archives/2026083003-perf-smell-gates-round6/sub/X3-report.md` and `git log --oneline 19dd4992..HEAD`; do not re-report those). Now look at what it did not cover:
1. tmux control plane (apps/gateway/src/tmux-client/**, tmux/**, control/**): how often is the session/window/pane tree refreshed and how (spawning `tmux list-*` subprocesses per event? per client? debounced?); how are `%output`-heavy panes handled when NO client is subscribed (still parsed / buffered? bounded?); pane history capture (`capture-pane` size, frequency, per-client duplication); pane emulator (`pane-emulator.ts`) cost per byte and whether it runs for panes nobody watches; local vs SSH external connections reconnect storms.
2. Persistence write frequency: agent step persister (`apps/gateway/src/agent/step-persister.ts`, stream-accumulator.ts, run-stream-handlers.ts) — is there a DB write per streamed delta or per step? Are agent messages/steps stored as ever-growing JSON blobs that are re-read and re-written (`updateAgentSession` on every event)? Settings/site/device stores written on every read? Measure with a bun script driving the persister with 5,000 deltas against an in-memory sqlite.
3. Agent WS broadcast (`apps/gateway/src/agent/ws-hub.ts`, supervisor.ts): per-delta fan-out cost, delta coalescing on the server, subscriber lookup, whether full session snapshots are sent instead of deltas anywhere.
4. Files & watch (`apps/gateway/src/files/**`, `watch/**`): directory browse reading stat for every entry serially? `fs.watch` fan-out, debouncing, recursive watchers on large trees, file upload/download streaming vs buffering whole files in memory.
5. HTTP layer: any per-request synchronous DB calls on hot endpoints (auth/session middleware on every request? `session-middleware.ts`), JSON responses that serialize large tables (`/api/tmux/tree`, node list), and rate of `SELECT` in middleware. 
Measure where feasible; report top hot spots with evidence.
